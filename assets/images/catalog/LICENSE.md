# Original MODA demo illustrations

The PNG files in this folder are original geometric illustrations authored for
this project by `tool/render_catalog_art.ps1`, from the demo catalog color data.
They are not manufacturer photography, measurements, or specifications.
These new illustrations and their drawing source may be reused under CC0-1.0.
No third-party photographs, logos, fonts, or remote image services were used as
source material for these illustrations. System fonts are rasterized for labels.

The four pre-existing photographs remain in the parent assets/images folder;
their original licensing/provenance is not changed or newly asserted here.
