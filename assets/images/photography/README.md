# MODA demo image provenance

94 photorealistic AI-generated images depict 24 fictional products and 46 color options. Twenty-four primary-color galleries have three images; 22 alternate colors have one. These are not verified manufacturer photographs, measurements, material specifications or real stock.

- Source: OpenAI built-in image_gen, generated for this project.
- Current files: opaque 720x960 JPEG, quality 84, 3:4 subject-aware framing.
- `PROVENANCE.json`: product/color/view mappings, source output filenames, dimensions and final SHA-256 checksums.
- `EDIT_HISTORY.json`: portable reference-edit records and exact prompts for eleven tall compositions. No machine-local paths or credentials are included.
- Side/detail images refer to the same generated primary product. Alternate colors were generated independently and fictional construction may differ.
- Missing-image fallback remains implemented; colors are never borrowed to hide a missing photo.

No retailer images were downloaded for these new assets. Output use is subject to the applicable generation-service terms; no exclusive copyright or third-party photography license is asserted. Review these terms before redistribution. The project owner has chosen not to grant an overall software reuse license; this does not determine image rights or replace existing asset notices.

The five former unknown-source PNGs in the parent directory have been replaced.
The new hero is a fresh text-only generated still life; the four product PNGs are
lossless conversions of their corresponding catalog outputs. See
../PUBLICATION_REPLACEMENTS.json for hashes, source records, exact hero prompts
and documented provider-rights conditions. Original bytes remain only in ignored
quarantine, not in the public set. Owner confirmation of account/customer authority,
earlier input rights and generated model imagery remains required; generation alone
is not proof of permission. Original geometric artwork remains in assets/images/catalog
with its existing separate notice. No new LICENSE is introduced.

See `docs/IMAGE_PROVENANCE.md` for the public asset inventory and limitations. The ready-to-use JPEGs are committed assets: private generation caches are not needed to run or build the app. Optional local re-export tooling expects an owner-supplied ignored source manifest and cache files; it is not part of installation.
